# Mascot sprites

These six production sprites are derived from the reviewer-approved original AI concept cutouts. The source options are 1200×1200 RGBA; only trimmed, proportionally downscaled 256×256 transparent WebP outputs are shipped. Export settings: WebP quality 90, alpha quality 100. High-resolution PNG concepts and the contact sheet are intentionally not bundled.

The sprites are visual-only, loaded from local files, covered by the service-worker precache, and drawn through the existing canvas transform. A failed or unsupported image load falls back to the equipped vector bird.
